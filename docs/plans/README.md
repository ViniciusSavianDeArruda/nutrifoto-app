# Plans

Planos de implementação para tarefas de múltiplos passos.

## Formato

Cada plano é um arquivo `docs/plans/<slug>.md` com:

```
# Título

**Status:** em andamento | concluído | cancelado
**Data:** YYYY-MM-DD

## Objetivo

O que será entregue ao final.

## Passos

1. [Passo] → verificar: [como confirmar que está feito]
2. [Passo] → verificar: [como confirmar que está feito]

## Notas

Decisões tomadas durante a execução, bloqueios encontrados.
```

Planos concluídos ficam como registro. Não apague — a trilha de decisões é útil.
